# Ən Yaxın Məktibimin Göstəriciləri.
Location-əsaslı interaktiv məktəb dashboardu: İstifadəçilər enlik və uzunluq daxil edərək yaxın məktəbləri tapa, nəticələri müqayisə edə və vizual qrafiklərdə analiz edə bilirlər. Python scraping (https://mekteb.edu.az/az/ və https://kataloq.gomap.az/ veb saytlarından) ilə məlumatlar toplanıb, Tableau-da vizuallaşdırılıb.

[Dashboardu burada izləyin](https://public.tableau.com/shared/PN9SSHBSF?:display_count=n&:origin=viz_share_link), həmçinin bütün scraping, cleaning prosesi və scrap olunan datasetlərində mənbəsini sizinlə paylaşıram.
